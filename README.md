## 🛠️ Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation
```bash
# Clone the repository
git clone https://github.com/yashvimal34/Node-JS.git

# Navigate to the project directory
cd Node-JS

# Install dependencies
npm install
```

### Running the Application
```bash
npm start
```
